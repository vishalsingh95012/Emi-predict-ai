# EMIPredict AI: Intelligent Financial Risk Assessment Platform

Machine learning platform that predicts **EMI eligibility** (classification) and the **maximum safe monthly EMI** (regression), with MLflow experiment tracking and a multi-page Streamlit app.

**Live app:** https://emipredict-ai-app.streamlit.app

## Features
- Real-time prediction: Eligible / High_Risk / Not_Eligible, class probabilities, maximum safe monthly EMI
- Warning when inputs fall outside the training range of the selected EMI scenario
- Data Explorer with interactive charts
- Model Performance page comparing all six models
- Admin page with create, read, update and delete operations on records
- MLflow tracking and Model Registry for every model

## Results (test set)
| Task | Model | Result |
|---|---|---|
| Classification | XGBoost | Accuracy 98.19%, F1 0.9819, ROC-AUC 0.9991 |
| Regression | XGBoost | RMSE 839 INR, MAE 388 INR, R-squared 0.9941 |

Three models were trained and compared for each task (Logistic / Linear Regression, Random Forest, XGBoost).

> **Note:** the dataset is synthetic (generated from the schema in the project brief), so scores are higher than real-world data would give.

## Project structure
```
app.py                  Streamlit prediction page
pages/                  Data Explorer, Model Performance, Admin CRUD
src/features.py         Feature engineering (shared by training and the app)
models/                 Best classifier, best regressor, label encoder
data/sample.csv         20K-row sample used by the app
clf_comparison.csv      Classification comparison table
reg_comparison.csv      Regression comparison table
01_cleaning_eda.ipynb   Data cleaning, EDA, feature engineering
02_models_mlflow.ipynb  Model training and MLflow tracking
requirements.txt
```

## Run locally
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## View the MLflow dashboard
```bash
mlflow ui --backend-store-uri sqlite:///mlflow.db
```
Open http://127.0.0.1:5000 (needs the `mlflow.db` file generated by running `02_models_mlflow.ipynb`).
